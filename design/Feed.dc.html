Buy the price, one read at a time.

The attested fixing as a paid API. No account and no key. A request without payment gets a 402 with the price; pay in USDC on NEAR and ask again.

01 · ASK GET /v1/fixing/H100 Your agent asks for the latest fixing.
02 · 402 Payment Required · 0.01 USDC The reply names the price and where to pay.
03 · PAY USDC on NEAR, signed A relayer covers gas, so the agent needs only USDC.
04 · 200 value + attestation The number arrives with the proof it was made in a TEE.

Indexes: H100, B200, INF-OUT. Prices are placeholders for testnet. Reading the latest fixing from the contract itself stays free.

# 1. ask
$ curl -i [YOUR-FEED-URL]/v1/fixing/H100
HTTP/1.1 402 Payment Required
x-payment-required: 0.01 USDC · near

# 2. pay and ask again
$ curl -H "x-payment: $SIGNED_USDC_TRANSFER" \
    [YOUR-FEED-URL]/v1/fixing/H100
HTTP/1.1 200 OK
{
  "id": 412,
  "index": "H100",
  "value": "3.06",
  "unit": "USD/GPU-hr",
  "at": "2026-11-11T14:00:00Z",
  "sources": 4,
  "attestation": "7f3c…a91e",
  "near_tx": "9Fh2…Lw4s"
}
 
// pays the 402 for you, then retries
import { paidFetch } from "@fastnear/x402";

const res = await paidFetch(
  "[YOUR-FEED-URL]/v1/fixing/H100",
  { account, maxPrice: "0.01" }
);
const fixing = await res.json();

// "3.06", with the proof beside it
console.log(fixing.value, fixing.attestation);
